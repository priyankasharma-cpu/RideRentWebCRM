# Demo image provenance

Hero daylight/night artwork and the white scooter image were generated for this project. Hero images are decorative backdrops; all page text, forms, tabs and buttons are real HTML/React controls.

The locally stored illustrative fleet photographs originated from these Unsplash image endpoints:

- `frontend/public/images/fleet-bike.jpg`: https://images.unsplash.com/photo-1568772585407-9361f9bf3a87
- `frontend/public/images/fleet-classic.jpg`: https://images.unsplash.com/photo-1558981403-c5f9899a28bc
- `frontend/public/images/fleet-car.jpg`: https://images.unsplash.com/photo-1519641471654-76ce0107ad1b
- `frontend/public/images/fleet-road.jpg`: https://images.unsplash.com/photo-1558981806-ec527fa84c39

Fleet images are illustrative and may depict a different model. Replace them with photographs of the agency's actual vehicles before production. Initial-based rider avatars and sample review text are illustrative, not real customer endorsements.

All vehicle/hero imagery is stored locally for the demo. Google Fonts enhance the typography when online; system sans-serif fallbacks work without them. The road animation is code-native SVG with separately animated wheels, scenery, road markings and suspension; it does not use a video.
